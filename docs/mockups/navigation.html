Choosing a folder, and keeping it fresh

Option B has no sidebar, so every navigation control has to live in the pane header. Here is what that header actually contains, and how the two sides differ.

The pane menu — where folders get chosen

Two different jobs, so the two sides diverge here. The Mac gets the real Finder picker; the phone gets a curated list plus a path box.

Phone side. No system picker exists, so the standard Android folders are hard-coded as a starting point, and anything you visit can be pinned. "Go to Path…" takes a raw path with tab-completion for when you know exactly where you're going.

One thing to confirm: favourites, pinned folders, and "reopen the last folder on launch" all mean writing a small amount of state to disk. That's UI convenience, not transfer history — but you did say no history is maintained, so tell me if you'd rather it start cold every launch.

When each pane refreshes
